# ACPS ResultHub - Feature Guide

From marks to merit - simple, safe and signed.

Teachers enter marks. The system does the maths. The Principal signs. Parents see the result.

## Exam Journey
*Follow every exam from marks to published result.*

Every exam moves through clear steps: marks entry, calculation, checking, signing and publishing. You always see the step an exam is in and the one button to press next.

**For:** IT Head, Principal, Vice Principal

1. Open an exam from the list.
2. Read 'What happens next' - it tells you the one thing to do.
3. Press the big button in 'Next action'.
4. If something is wrong, use 'Return with reason' - nothing is lost.

**NB:** A published result can be withdrawn, fixed and published again. Students never see unpublished results.

**In the future:** Same screens; the server will keep the status and send alerts (SMS/email) when an exam changes step.

## Marks Desk
*Enter marks class by class - even from a phone.*

Teachers see only their own classes and subjects. Each student has a small card with boxes for every part (Objective, Subjective, Practical, Monthly test). Totals show while you type.

**For:** Teacher

1. Choose the exam, then press 'Enter marks' next to your class and subject.
2. Type the marks. Use a status (for example Absent) instead of marks when needed.
3. Press 'Save draft' as often as you like.
4. Press 'Submit marks' when everything is correct - the batch locks.

**NB:** After Submit you cannot change marks. Use Correction Desk. Need more days? Use Extra Time.

**In the future:** Marks will save to the server automatically while typing; offline saving can be added.

## Attendance Book
*Working days, days present and a remark for every student.*

Class teachers fill attendance and a short remark once per exam. It prints on the transcript and feeds the attendance rules.

**For:** Teacher

1. Choose your class and the exam.
2. Type working days and days present.
3. Choose a remark.
4. Press Save.

**NB:** Attendance locks when the exam is published. Below 50% attendance shows a warning flag.

**In the future:** Daily attendance from the ANS (Absent Notification) module will fill these numbers automatically.

## Extra Time
*Ask for more days. Get a clear yes or no.*

A teacher asks for more days with a reason. The IT Head recommends, the Principal approves, and the exam's last date moves by itself. The limit (2 times) is set in Rule Studio.

**For:** Teacher, IT Head, Principal

1. Teacher: press 'Ask for more time', choose the exam, write the reason.
2. IT Head: press Recommend (or Reject).
3. Principal: press Approve (or Reject).
4. The end date of the exam changes automatically.

**NB:** One exam can be extended at most the number of times set in Rule Studio.

**In the future:** Teachers will get an SMS or app alert when the answer is ready.

## Correction Desk
*Fix a mark safely, with two approvals and a trail.*

After marks are submitted a teacher cannot edit them. A correction request needs approval from the IT Head and the Exam Authority. The old and new marks are kept in the Change Trail.

**For:** Teacher, IT Head, Exam Authority

1. Teacher: press 'New correction request', choose batch, exam, student and part.
2. Type the correct marks and the reason.
3. IT Head and Exam Authority press Approve.
4. After both approvals the marks change by themselves.

**NB:** If one approver rejects, nothing changes.

**In the future:** Approvers will be notified by SMS or email.

## Grace Desk
*Small extra marks - limited, approved, never hidden.*

For a student just below the pass mark. The limit (marks and subjects) is set in Rule Studio. Original marks never change; grace is shown separately on the transcript.

**For:** IT Head, Exam Authority

1. IT Head: choose exam, class, student and the failed subject.
2. Type the grace marks and the reason.
3. Exam Authority presses Approve.
4. Approved grace counts in the result at once.

**NB:** Pending grace marks do not count until approved.

**In the future:** A written approval letter (PDF) can be attached to each grace.

## Pass Switch
*Pass one student at 33 with a single tap.*

Everyone passes at 45. If the school decides to pass a failed student at 33, switch only that student. Their subject pass, part pass, joint pass and grade then use the 33 values. Nobody else changes.

**For:** IT Head, Exam Authority, Principal

1. Choose the exam (or the yearly aggregate).
2. Failed students are listed with a preview of the result at 33.
3. Write a short reason and press 'Switch to 33 rule'.
4. To undo, press 'Back to 45'.

**NB:** The transcript shows that the 33 rule was used. Actual marks are never changed.

**In the future:** The approving authority's name and date will be stored with each switch.

## Result Board
*Every student's marks, grade, GPA and position.*

Pick an exam or the whole year and a class. See GPA, grade, pass or fail and merit position (section, class, group) at once. Open any student for the printable transcript.

**For:** IT Head, Exam Authority, Principal, Vice Principal, Teacher

1. Choose Exam and Class at the top.
2. Narrow by version, section or group if you want.
3. Press 'Transcript' to open one student.
4. Press 'Export Excel' to save the list.

**NB:** Teachers see published results of the section where they are class teacher.

**In the future:** Results will be calculated and stored on the server when an exam is verified.

## Transcript Studio
*A clean transcript in English or Bangla - print or save as PDF.*

Subjects, marks, grade, highest marks, GPA, position, attendance, remarks and digital signatures on one A4 page.

**For:** IT Head, Principal, Student, Parent

1. Open a result.
2. Switch language if needed.
3. Press 'Print or save as PDF'.

**NB:** Choose 'Save as PDF' in the print window.

**In the future:** School seal and signature pictures will be added from Safe Box.

## Report Shelf
*Eight ready reports. Print or Excel in one tap.*

Tabulation sheet, Merit list, Subject-wise result, Fail list, Grade sheet, Progress report, Teacher marks sheet and the Mark Blueprint chart.

**For:** IT Head, Exam Authority, Principal, Vice Principal, Teacher

1. Choose a report card.
2. Choose exam and class.
3. Press Print or Export Excel.

**NB:** Reports need marks to be entered first.

**In the future:** New reports can be added without changing the other pages.

## SSC Pathway
*Class X: school exams, eligibility list and Board results.*

Class X has four school exams (First, Second, Pre-Test, Final Test). The rule 'who can sit for SSC' is automatic and editable. The Board result is typed in after the Board publishes it.

**For:** IT Head, Exam Authority, Principal

1. Open the 'Who can sit for SSC' tab to see the list.
2. Press 'Form fill-up list' to export eligible students.
3. After the Board result: open 'SSC Board results' and press Add or edit.

**NB:** Eligibility rule: pass the Final Test and attendance 50% (change in Rule Studio).

**In the future:** Board result import from the Board's Excel file.

## Promotion Desk
*Year-end promotion in three calm steps.*

Decisions (Promoted, Re-exam, Repeat, Hold, Passed Out) come from editable rules. Principal approves, then one button moves students to the next class with new roll by merit and starts the new session.

**For:** IT Head, Principal

1. IT Head: press 'Prepare promotion list'.
2. Principal: press 'Approve the list'.
3. IT Head: press 'Run rollover' (take a backup first).

**NB:** Class VIII to IX students get Science by default - correct group and 4th subject afterwards.

**In the future:** Old sessions will stay readable from an archive on the server.

## Class Explorer
*See every class, section, subject, teacher and student.*

Start with Class I to X cards. Open a class to see its sections with class teachers, all its subjects (with marks and who teaches them) and all its students.

**For:** IT Head, Exam Authority, Principal, Vice Principal, Teacher

1. Open a class card.
2. Use the tabs: Sections, Subjects, Students.
3. IT Head: press 'Plan teachers' to assign teachers.

**NB:** Numbers update at once when you add students or teachers.

**In the future:** Timetable and room plans can be added to each section.

## Student Book
*Every student: profile, subjects, teachers and results.*

Search, add, correct and export students. Open a student to see their subjects with the teacher of each, their results and pass rule.

**For:** IT Head, Teacher, Principal

1. Search by name, ID or mobile, or use the filters.
2. Press View for the full profile.
3. IT Head: press Edit to correct anything or Add student.

**NB:** Student ID never changes. Roll changes each session.

**In the future:** Photo, documents and family details can be added as new fields from Field Builder.

## Easy Import
*Bring in hundreds of students from Excel in four steps.*

Upload Excel, CSV or JSON from the SICS system. Columns are matched for you; unknown columns can become new custom fields. Problems are shown row by row before anything is saved.

**For:** IT Head

1. Download the sample file.
2. Fill it or choose your own file.
3. Check the column matching.
4. Press Import.

**NB:** Same ID = update the student. New ID = add a student.

**In the future:** A direct link to SICS will replace the file step.

## Subject Picker
*Choose the 4th subject for Class IX and X students.*

The choices come from Subject Map. The result uses it for the bonus point.

**For:** IT Head

1. Choose class and group.
2. Pick the 4th subject for each student.
3. Press Save.

**NB:** Religious Studies is chosen automatically from the student's religion.

**In the future:** Students or parents will be able to request a choice online.

## Teacher Desk
*All teachers, their work and their access in one place.*

See every teacher with the subjects, sections and class they handle. Open a teacher to add or remove assignments, allow or stop marks entry and see the login account.

**For:** IT Head

1. Search a teacher or press 'Add teacher'.
2. Open a teacher.
3. Add assignments (class, section, subject) or class teacher duty.
4. Use 'Allow marks entry' to switch access on or off.

**NB:** A subject teacher can teach many sections. A section has one class teacher.

**In the future:** Teacher leave and substitute teacher can be added.

## Teacher Planner
*Assign class teachers and subject teachers in minutes.*

Pick a class and section: every subject is listed with a teacher box. Or pick a subject and give it to teachers section by section. Copy a whole plan from another section.

**For:** IT Head

1. Choose Class, Version and Section.
2. Choose the class teacher.
3. Choose a teacher for each subject.
4. Press Save plan.

**NB:** Teachers only see classes assigned here.

**In the future:** Yearly plan copy: copy last year's plan to the new session in one tap.

## Access Keys
*Decide who can sign in and what each role may do.*

Create user accounts and switch them on or off. Tick boxes decide what every role can do - menus and buttons change at once.

**For:** IT Head

1. Users: add a person, choose the role.
2. Permissions: tick or untick a box.
3. Switch an account to Inactive to stop sign-in.

**NB:** The IT Head always has every permission.

**In the future:** Passwords will be stored safely on the server and sign-in can use SMS codes.

## Mark Blueprint
*Design how every subject's marks are built.*

For each class and group: full marks, pass marks (45 and 33), parts (Objective, Subjective, Practical, Monthly), conversion percent, joint subjects and the 4th-subject rule. Copy, edit and print the chart.

**For:** IT Head

1. Open a blueprint or press Copy to start from an existing one.
2. Change subjects, marks and parts.
3. Press 'Fill 33 pass marks' to compute the 33 set.
4. Press Save. Use 'Chart' to print.

**NB:** New subject after marks entry? Add it here - students show 'Incomplete' until marks are entered.

**In the future:** Version history: see who changed a blueprint and restore an older one.

## Exam Planner
*Decide which exams each class has and how much each counts.*

Class I-IX: First, Second, Final. Class X: First, Second, Pre-Test, Final Test, then SSC. Change exams and weights any time.

**For:** IT Head

1. Open a scheme.
2. Add, remove or change exams and weights.
3. Make sure school exams add to 100.
4. Save.

**NB:** Class X weights 20/20/25/35 are a suggestion.

**In the future:** Exam routine and seat plan can attach to each exam.

## Subject Map
*Which subjects each class and group studies.*

Main, optional and 4th-subject roles for every class and group.

**For:** IT Head

1. Open a map or Add.
2. Add subjects and choose the role.
3. Save.

**NB:** 'main or fourth' = counted as main unless the student picks it as 4th.

**In the future:** Elective subject limits per group.

## Subject Library
*The master list of all subjects and Board codes.*

Add or correct a subject. The code is also its ID.

**For:** IT Head

1. Press Add course.
2. Type code and name.
3. Choose type and save.

**NB:** Use Board codes (Math 109).

**In the future:** Bangla names and Board syllabus links.

## Grade Book
*Marks range to grade and grade point.*

Separate tables for the 45 rule, the 33 rule and the final GPA letter.

**For:** IT Head

1. Open a table.
2. Edit rows (from marks, letter, grade point).
3. Save.

**NB:** A mark below the last row is F.

**In the future:** Different tables for primary and secondary if the school needs them.

## School Lists
*Classes, versions, groups, shifts, sections, sessions.*

The small lists the whole system depends on. Add Section C or a new Shift in seconds.

**For:** IT Head

1. Open a list.
2. Press Add or Edit.
3. Save.

**NB:** Deleting something already used may hide students from lists.

**In the future:** Campus (branch) specific lists.

## Status Codes
*Absent, Withheld, Transferred... and what each does.*

Codes a teacher can choose instead of marks.

**For:** IT Head

1. Add or edit a code.
2. Choose the effect (zero marks).
3. Save.

**NB:** Codes AB, EX, WH, EXP, TR give 0 marks and 0 GP.

**In the future:** Auto-fill from the Absent Notification module.

## Rule Studio
*Change any rule, number or formula yourself.*

Numbers (pass percent, grace limit), formulas with a test box, and IF-THEN conditions for promotion, SSC eligibility and report flags. No developer needed when the management changes a rule.

**For:** IT Head

1. Numbers tab: change a value, press Save.
2. Formulas tab: edit, type test numbers, check the answer, Save.
3. Conditions tab: edit IF and THEN lines, Save.
4. Calculate again to see new results.

**NB:** Use 'Reset to original' if you are unsure.

**In the future:** Rule history with 'who changed what' and one-tap restore.

## Name Studio
*Rename any menu, title or column.*

Type a new name (for example in Bangla) and it changes everywhere.

**For:** IT Head

1. Search the name.
2. Type the new name.
3. Press Save names.

**NB:** Empty box = original name.

**In the future:** Full Bangla language pack.

## Field Builder
*Add a new information column - no developer.*

Add a field to Students, Teachers or Courses. It appears on forms, lists, Excel export and import.

**For:** IT Head

1. Press Add custom field.
2. Choose where, name and type.
3. Save - it appears at once.

**NB:** Keys start with cf_ and cannot change later.

**In the future:** Fields for Parents and Sections.

## Parent Connect
*Message a whole class in one go.*

Choose class, section and who to message (parents, students or both). Templates fill in the student's name and exam automatically.

**For:** IT Head, Principal, Teacher

1. Choose class and section.
2. Choose a template or write a message.
3. Check the example.
4. Press Send.

**NB:** The SMS gateway is not connected yet - messages are saved in the log.

**In the future:** Connect an SMS provider to really send. See Future Plan.

## Help Desk
*Describe a problem. The IT team answers here.*

Create a ticket, follow replies and see when it is solved.

**For:** IT Head, Teacher, Principal, Student, Parent

1. Press New ticket.
2. Describe what happened.
3. Come back to read the reply.

**NB:** Write which page you were on.

**In the future:** Photo attachment and WhatsApp alert.

## Change Trail

Every create, edit and delete is written automatically and kept for 5 years.

**For:** IT Head, Exam Authority, Principal

1. Filter by place or action.
2. Search a name or record.
3. Export to Excel.

**NB:** The trail cannot be edited.

**In the future:** Stored on the server with yearly archive.

**For:** IT Head, Teacher, Principal, Student

1. Change password if needed.
2. IT Head: edit school information.
3. IT Head: Download backup before big changes.

**NB:** Daily automatic backups arrive with the server version.

**In the future:** Cloud backup every night.
